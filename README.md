# Kartikay Patni's Portfolio

A modern, responsive portfolio website built with Next.js, Tailwind CSS, and Three.js. Features a sleek design with dark mode support and interactive 3D elements.

## Features

- 🎨 Modern and clean design with pastel color scheme
- 🌓 Dark mode support
- 🎭 Smooth animations with Framer Motion
- 🎮 Interactive 3D elements using Three.js
- 📱 Fully responsive design
- ⚡ Fast performance with Next.js

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Three.js / React Three Fiber
- Framer Motion
- next-themes

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/KArtik-34/portfolio.git
cd portfolio
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project Structure

```
/
├── components/      # React components
├── lib/            # Constants and utilities
├── pages/          # Next.js pages
├── public/         # Static assets
└── styles/         # Global styles
```

## Customization

1. Update personal information in `lib/constants.ts`
2. Modify theme colors in `tailwind.config.ts`
3. Add or modify sections in `components/sections/`
